# test-case-design

一个用于设计软件测试用例的 Agent Skill。按一套定版的设计标准（v2）编写、补充和评审测试用例，适用于任何项目。

## 这套标准包含什么

- 14 个范围维度逐项必查，不适用的写明 N/A 理由
- 8 种设计方法综合使用：等价类划分、边界值分析、判定表法、因果图法、状态迁移法、场景法、正交实验法、错误推测法
- 5 类测试全覆盖：功能测试、性能测试、兼容性测试、易用性测试、安全测试
- 固定 14 个字段；编号 Test001 起、一个项目终身顺延，作废号不复用
- 优先级只设 P0 / P1 / P2，P0 占比不超过整套用例的 15%

## 文件

- `SKILL.md`：技能的流程与硬性规则
- `references/design-standard-v2.md`：设计标准全文（维度、方法、类型、字段、交付自查清单）
- `scripts/check_cases.py`：用例 CSV 机械校验脚本
- `skill.yaml`：技能登记信息

## 安装

把整个 `test-case-design` 文件夹放进 Agent 宿主的技能目录即可（例如 Muse 的 `~/workspace/custom-skills/`），文件夹名保持 `test-case-design` 不变。

## 校验用例

用例数据文件（CSV，含全部 14 个字段）写好后运行：

```bash
python3 scripts/check_cases.py <用例文件.csv>
```

脚本检查编号格式与重号、P0 占比、优先级合法性、步骤与期待结果行数对应、设计方法与主要类型是否使用规范名称且全覆盖；编号跳号只告警，提示对照作废号登记核销。
